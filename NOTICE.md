This project modifies and tests the AI behavior of the open-source Forge / NeoForge engine. Forge source is distributed under GNU GPL version 3. The upstream project is maintained by the Card Forge contributors at https://github.com/Card-Forge/forge.

NeoForge is an unofficial distribution. This project is independent and is not affiliated with Card Forge or Wizards of the Coast. Magic: The Gathering names and card text are property of Wizards of the Coast; card names are used only to identify compatibility test cases.

The compiled test-engine JAR is a local verification artifact for the pinned NeoForge 1.0.28 base. Its corresponding source overlays and tests are included in this repository; the upstream engine source remains available from the linked project.
