Its `{G}/{W}` combo output was also interpreted as colorless by the existing battery evaluator. The `molten-slagheap` profile now maps both Molten Slagheap and Saltcrusted Steppe to `ManaRitualBattery.0`, while the opt-in evaluator handles Saltcrusted's `Combo G W` output as X mana in the listed colors. It holds when no castable noninstant needs the storage, ordinary sources already cover that spell, only an instant benefits, or the storage and activation cost cannot bridge the remaining mana. Native source selection, color assignment, payment, and spell resolution remain authoritative.

The implementation extends the existing `ManaAi` path and the profile-only admission already used by `ComputerUtilMana`; no card script or default profile changed.
