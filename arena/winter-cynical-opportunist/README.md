# Winter, Cynical Opportunist lab

The `winter-cynical-opportunist` profile leaves the printed script and combat evaluation intact. On the delirium end-step trigger, it selects the highest-valued legal permanent card first, excluding a legendary duplicate already on the battlefield. It then selects the lowest-valued nonpermanent graveyard cards needed to reach the script's aggregate four-card-type threshold, and stops. If no eligible return target or sufficient nonpermanent type support exists, it declines the trigger. The native effect exiles the selected pile and returns the permanent with its finality counter.

The native baseline reproduced the poor generic exile choice. The focused fixture passes 13 checks for trigger eligibility, best-permanent choice, nonpermanent support, stopping at four types, native chained resolution/finality behavior, duplicate-legend protection, insufficient support, and default-profile parity. The full NeoForge 1.0.28 gate passes 5,733 checks across 57 suites (13 new plus all 5,720 prior at exact counts); the installed-file guard checked 21,729 hashes with zero changes.

Paired two-player custom-deck exposures used identical decks and 120-second clocks on seeds 131011 and 131012. Off: zero Winter casts, attack triggers, and delirium triggers on both seeds. On: one Winter cast per seed; 12 attack triggers and 5 delirium triggers on 131011, and 13 attack triggers and 4 delirium triggers on 131012. All four games exited without exceptions or clock limits. The gate fixture verifies the native return effect; game logs show cast and trigger use. Card-use evidence only, no strength claim. Raw logs, commands, witnesses, and hashes are in `verification-summary.json`.
